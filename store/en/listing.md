## Name (≤ 45 chars)
Website Insights Tool: Rank, Age, Tech & SEO

## Summary / short description (≤ 132 chars)
See any site's popularity rank, domain age, tech stack, SEO checks and speed in one click. Free data, no account, no tracking.

## Description

Curious how big a website really is, how old it is, and what it's built with? Click the icon on any site and get the answers in seconds.

WHAT YOU SEE
• Popularity rank: the site's global rank in the Tranco top 1 million (a research-grade ranking combining several traffic sources), a 30-day trend chart, and a traffic tier ("Top 10,000 — high traffic").
• Domain age: registration and expiry dates, registrar, DNSSEC and name servers, straight from the official registry records (RDAP).
• Tech stack: about 120 technologies, including React, Next.js, Vue, WordPress, Shopify, Webflow, Google Analytics, Cloudflare, Vercel, Nginx and more, with versions where available.
• SEO check: title, meta description, H1, alt text, canonical, robots.txt, sitemap, structured data, Open Graph, Twitter cards and security headers, with a score and clear pass/warn/fail marks.
• Speed: TTFB, FCP, LCP and CLS measured in your own tab, instantly.

OPTIONAL, WITH FREE KEYS
• Real-user Core Web Vitals from the Chrome UX Report (28-day data from real Chrome users), with a free Google API key.
• PageSpeed Insights lab tests (mobile and desktop).
• Cloudflare Radar rank, site categories and top countries, with a free Cloudflare token.
Everything works without keys. Keys only unlock the extra data, and step-by-step instructions are built in.

PRIVATE BY DESIGN
• No servers, no account, no analytics. The developer never receives your data.
• Works only when you click the icon, and only on the tab you clicked.
• Minimal permissions: activeTab, scripting, storage.
• Data comes straight from free public sources (Tranco, registry RDAP servers, Google, Cloudflare). The privacy page lists exactly what is sent where.
• Open source: https://github.com/jliushi/website-insights-tool

GREAT FOR
SEO specialists, marketers, domain investors, developers, journalists and anyone who wants to size up a website before trusting it, buying from it or competing with it.

Available in English and Simplified Chinese.

Note: popularity is shown as a rank, not as exact visit counts. Exact traffic numbers are only available from paid panel data.
