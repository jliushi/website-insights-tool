# 商店介绍 —— 简体中文

## 名称
网站洞察工具：排名、域名年龄、技术栈与SEO

## 简介（≤ 132 字符）
一键查看任意网站的流行度排名、域名年龄、技术栈、SEO 检查和速度。免费数据源，无需账号，不追踪。

## 详细描述

想知道一个网站到底有多大、建站多久、用什么技术搭建？在任意网站上点击图标，几秒内即可得到答案。

你能看到
• 流行度排名：网站在 Tranco 全球前 100 万中的排名（综合多种流量来源的研究级排名），附 30 天走势图和流量等级（如“前 10,000 —— 流量很高”）。
• 域名年龄：注册与到期日期、注册商、DNSSEC 和域名服务器，直接来自注册局官方记录（RDAP）。
• 技术栈：约 120 种技术，包括 React、Next.js、Vue、WordPress、Shopify、Webflow、Google Analytics、Cloudflare、Vercel、Nginx 等，尽可能显示版本号。
• SEO 检查：标题、Meta 描述、H1、图片 alt、canonical、robots.txt、站点地图、结构化数据、Open Graph、Twitter 卡片和安全响应头，附得分和清晰的通过/警告/未通过标记。
• 速度：在你自己的标签页中即时测得的 TTFB、FCP、LCP 和 CLS。

可选功能（使用免费密钥）
• Chrome UX Report 真实用户 Core Web Vitals（真实 Chrome 用户 28 天数据），需免费 Google API 密钥。
• PageSpeed Insights 实验室测试（移动端和桌面端）。
• Cloudflare Radar 排名、网站分类和主要国家，需免费 Cloudflare 令牌。
不设置密钥也能正常使用；密钥只用于解锁额外数据，扩展内附有分步获取说明。

隐私优先
• 没有服务器、没有账号、没有统计分析，开发者不会收到你的任何数据。
• 只在你点击图标时工作，且只作用于你点击时所在的标签页。
• 最少权限：activeTab、scripting、storage。
• 数据直接来自免费公开数据源（Tranco、各注册局 RDAP 服务器、Google、Cloudflare），隐私页面逐项列出发送内容与接收方。
• 开源：https://github.com/jliushi/website-insights-tool

适合人群
SEO 从业者、营销人员、域名投资者、开发者、记者，以及任何想在信任、购买或竞争之前先摸清一个网站底细的人。

支持英文和简体中文界面。

说明：流行度以排名形式展示，而非精确访问量。精确流量数字只能来自付费的样本数据。
